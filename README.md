# Игра «Тетрис» на Python

Классическая аркадная игра «Тетрис», реализованная на языке Python с использованием библиотеки `pygame`. 
Проект выполнен в рамках лабораторной работы №8 (сборка приложения в .exe и создание установочного пакета).

## 📸 Скриншот игры
![Скриншот игры](ссылка_на_вашу_картинку_или_удалите_эту_строку)

## 🎮 Функционал
- Игровое поле 10×20.
- Генерация фигур по системе «7-bag» (каждая из 7 фигур выпадает один раз за цикл).
- Обработка коллизий и поворотов фигур.
- Подсчет очков и количества собранных линий.
- Определение конца игры (Game Over) с возможностью быстрого перезапуска.

## ⌨️ Управление
- **← / →** — движение фигуры влево/вправо.
- **↑** — поворот фигуры по часовой стрелке.
- **↓** — ускорить падение фигуры.
- **Пробел (Space)** — мгновенный сброс фигуры (Hard Drop).
- **R** — перезапуск игры (после Game Over).
- **Esc** — выход из игры.

## 🚀 Как запустить

### Вариант 1: Готовый установщик (для пользователей Windows)
1. Перейдите в раздел [**Releases**](../../releases) этого репозитория.
2. Скачайте файл `Tetris_Setup.exe`.
3. Запустите его и следуйте инструкциям мастера установки.
4. После установки запустите игру с ярлыка на рабочем столе.
